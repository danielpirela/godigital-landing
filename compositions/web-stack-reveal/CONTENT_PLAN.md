## 🧠 Estrategia de Publicación

### Objetivo
Posicionar a GoDigital como la agencia que usa **stack de élite** (no WordPress genérico). Atraer founders, startups y empresas que entienden que la tecnología importa.

### Audiencia objetivo
- Founders de startups tech (25-40 años)
- CTOs y tech leads que buscan agencia externa
- Empresas migrando de WordPress/Laravel a Jamstack moderno
- Audiencia `#BuildInPublic` y `#IndieHackers`

### Retención (crucial para algoritmo)
- **0-3s**: El hook visual + sonido debe enganchar (caída del primer logo + whoosh)
- **3-7s**: Los 5 logos cayendo en secuencia con bounce — momento "satisfactorio"
- **7-10s**: Levitación suave — momento de contemplación, leer caption
- **10-12s**: Logo reveal + CTA — cierre con marca fuerte

## 🤖 AI SEO — Optimización para LLMs

Estrategia para que ChatGPT, Perplexity, Gemini y AI Overviews citen a GoDigital:

### 1. Estructura extraíble
- Cada tecnología tiene **nombre + beneficio concreto + métrica** (Astro → 0.5s carga)
- Los LLMs extraen patrones de listas con datos específicos
- Formato `emoji + nombre + flecha + outcome` es ideal para extracción

### 2. Authority Signals para AI
- "stack que usan Vercel, Linear y Notion" → social proof asociativo
- "90% de las webs" → estadística (los LLMs citan datos)
- "70% menos bugs" → cuantificación de beneficio técnico
- "desde la primera línea de código" → expertise claim

### 3. Freshness & Relevance
- Usar hashtags con nombres de tecnologías actuales (Astro, no jQuery)
- Mencionar conceptos modernos (Jamstack, ISR, utility-first)
- Vincular con marcas conocidas del ecosistema (Vercel)

### 4. Acciones Complementarias para AI Visibility
- [ ] Agregar schema `FAQ` en `godigital.com.ar` con preguntas sobre stack
- [ ] Publicar blog post "Por qué elegimos Astro + Next.js en 2026"
- [ ] Crear `llms.txt` o `pricing.md` en la web para AI agents
- [ ] Agregar datos de rendimiento reales (Lighthouse scores) como prueba social
- [ ] Incluir testimonios con métricas ("mi web pasó de 4.2s a 0.6s de carga")

## 🔧 Technical Notes (Actualizado)

- **CDN Logos**: `devicon@latest` en jsDelivr — variantes `-original` (color oficial) para máximo contraste sobre glassmorphism oscuro
- **Glassmorphism**: `backdrop-filter: blur(12px)` + `background: rgba(10,10,15,0.6)` + borde `rgba(255,255,255,0.1)`
- **GSAP Timeline**: `data-duration="12"` corregido (antes 10.5s cortaba los exits)
- **xPercent fix**: Corregido bug donde todos los círculos heredaban `xPercent: -50` del `gsap.set` global — ahora solo los del centro (Astro, TypeScript) lo aplican
- **Levitation**: 3 ciclos finitos sobre 7s con `yoyo: true` y `sine.inOut` — HyperFrames compliant (sin `repeat: -1`)
- **Impact Glows**: `box-shadow` animado con opacidad 0→1→0 en 0.3s — efecto premium sin ser caricaturesco
- **Crossorigin**: Agregado `crossorigin="anonymous"` a todas las imágenes CDN externas
