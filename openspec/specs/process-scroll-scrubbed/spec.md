# Process Scroll Scrubbed

## Purpose

The Process section presents the agency's working method via a scroll-scrubbed vertical timeline. As the user scrolls, the timeline connector line grows, numbered circles rotate 360°, and step text reveals word-by-word. SVG fluid curves (generated by mmx or SVG path) connect timeline steps visually. This is a medium-intensity, content-forward animation that rewards scrolling.

Ref: Proposal §Approach (Process row) · §Capabilities (process-scroll-scrubbed)

## Requirements

### Requirement: PROCESS_SCROLL_SCRUBBED_TIMELINE
The Process section SHALL use `gsap.to()` with `ScrollTrigger` `{ scrub: 1.5 }` to tie timeline progress to scroll position.

The vertical connector line SHALL scale `scaleY: 0 → 1` as the user scrolls through the section.

Numbered circles (1–5) SHALL rotate `rotation: 0 → 360` tied to the same scrub progress.

#### Scenario: Scroll scrubs the timeline forward
Given the user scrolls from the top of the Process section to the bottom
When scroll progress reaches 50%
Then the connector line is 50% extended
And circle 1 has rotated 180°
And circle 2 has rotated 90°

### Requirement: PROCESS_WORD_BY_WORD_TEXT_REVEAL
Each process step's description text SHALL reveal word-by-word using GSAP `fromTo` with per-word `y: 20 → 0` and `opacity: 0 → 1`.

Word-by-word reveal SHALL be triggered when the step's numbered circle rotates into the 90°–180° range (midpoint of rotation).

Text elements SHALL use `display: inline` words wrapped in `<span class="word">` with `overflow: hidden` parent for clipping.

#### Scenario: Step text reveals as circle rotates
Given step 1 has 8 words
When the scroll scrub reaches the step's trigger point
Then words appear sequentially over 0.8 seconds
And each word fades in with y-translation
And the total animation completes before the next step triggers

### Requirement: PROCESS_MMX_SVG_FLUID_CURVES
The Process section SHALL render mmx-generated SVG fluid curves between timeline steps using `assets/generated/bg/process-curve.svg` if available.

Fallback: An inline SVG `<path>` element with a bezier curve connecting step positions using `fill: none`, `stroke: var(--color-electric-blue)`, `stroke-width: 2`, `opacity: 0.4`.

The SVG curves SHALL be decorative (non-interactive) and positioned absolutely behind the timeline content at `z-index: 0`.

#### Scenario: SVG curve renders as fallback
Given `assets/generated/bg/process-curve.svg` does not exist
When the Process section renders
Then an inline SVG path with bezier curves is rendered
And the path connects step 1 to step 2 to step 3
And the stroke color matches `--color-electric-blue`
